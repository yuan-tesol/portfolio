# Teaching Philosophy Site

Open `index.html` in a browser to view the finished static site.

## Google Sites Structure

Use these sections when recreating the page in Google Sites:

1. Hero: Yuan's teaching philosophy headline, personal educator identity, and visible thesis panel.
2. Section buttons: Identity, Beliefs, Approach, Theory, and Evidence.
3. Teacher Identity: student-centered, asset-based, reflective, welcoming, multimodal, and advocating.
4. My Core Beliefs: four clear beliefs about assets, intentional language support, meaningful interaction, and multiple ways to assess understanding.
5. Teaching Approach: bridge visual from student assets to meaningful STEM participation, plus scaffold toolbox.
6. Theory to Practice: Krashen, Swain, Long, Vygotsky, Halliday, and Garcia and Li Wei.
7. Evidence: linked artifact cards for LS 6300 PERA, TEL 5200 MASS, TEL 6210 materials modification, and TEL 6350 TIAR.
8. Future Growth: professional learning, teacher inquiry, collaboration, translanguaging, STEM education, and project-based learning.
